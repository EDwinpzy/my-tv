## 二、判定依据（不依赖单一信号）

1. **内容性质**：探测数据（`report_round2.json`）显示各源可搜索命中「哪吒2、狂飙」等 2025-2026 热门院线/独播内容，经免费 macCMS API 以 1080p 提供。国内持牌平台（爱优腾芒）均不提供此类开放采集接口，无授权平台不可能合法分发这些内容。
2. **基础设施特征**：AES-128 加密 HLS（6 站）、编号镜像域（hhkan0/1、hongniuzy2）、46 候选站中 27 站域名已死的高频翻新、对数据中心 IP 的出口封锁（好好看、黑木耳对腾讯云出口拦截）——均为规避检测的灰色基础设施惯用手法。
3. **来源社区自认**：候选清单本身来自「采集站收集帖」（waifu-project issue 等），该生态即盗版内容分发供应链。
4. **无任何许可痕迹**：无版权页、无授权链说明、无广告/会员等合法商业模式，API 主机无公开门户。

## 三、风险评估（结合本项目现状）

- **架构上已有的边界**（工程措施，非法律豁免）：补线源仅参与播放兜底，不生成目录卡片（单一内容来源原则）；播放流量经自建中继，不直连源站 CDN。
- **个人/家庭自用**（当前测试记录中的定性）：主要法律风险在传播端（源站运营方）；终端用户观看在国内现行执法实践中被追责的案例极少，风险低但不为零。
- **⚠️ 高风险项——会员收费体系**：项目含卡密/会员付费激活（activate 路由、卡密管理）。**对无授权内容收费 = 经营性传播**，若公开分发 App 并收费，法律风险显著提升（侵犯信息网络传播权，且收费情节是量刑/赔偿加重因素）。
- **CloudBase 公网网页版**：`/web/` 为公开可访问 URL，聚合播放同样构成公开传播面。

## 四、建议（决定权在项目所有者）

1. **维持纯个人/家庭自用**：不公开分发 APK、不对外售卖卡密，当前风险敞口可控。
2. **若计划公开分发或持续收费**：必须先替换为授权内容源（各平台官方开放 API、合规聚合服务），否则建议移除付费体系。
3. **网页版访问面收敛**：如仅自用，可考虑为 `/web/` 增加访问口令，缩小公开传播面。
4. 源站可用性已由测速自动降权机制兜底（`_mcms_site_order`），合规层面的巡检建议随季度复核一次（域名翻新后重新评估）。
